    When Does Memory Help? A Cost-Aware Evaluation of Long-Term Memory in Tool-Using LLM Agents

    Researchers introduced MERIT, a new benchmark that evaluates how long-term memory affects task-executing LLM agents under strict cost and token accounting. The study found that using memory dramatically increases task success—raising it from a baseline of 0.00 up to 1.00—though swapping memory implementations can alter success rates by up to 60 points. Furthermore, update-on-write memory systems significantly outperformed embedding retrieval when handling updated facts, while full dialogue replay was proven to never be economically viable.

    Damage-Aware Bandit Pruning for Vision and Language Transformers

    This paper introduces a damage-aware multi-armed bandit framework to improve structured post-training pruning for vision and language transformers. By evaluating 'paired damage' (masked loss minus base loss) on calibration batches, the method sequentially identifies and zeroes out attention heads and MLP channels with minimal performance loss. Experiments across a wide range of models demonstrate that this approach consistently reduces performance degradation compared to traditional pruning baselines under a fixed evaluation budget.

    CriticGen: Generation-Aware Evaluation as Actionable Feedback

    Researchers have introduced CriticGen, a generation-aware framework designed to provide fine-grained, actionable feedback for evaluating and improving large language models. By dynamically creating instance-specific rubrics, CriticGen enables models to diagnose flaws and jointly produce scores, explanations, executable suggestions, and refined answers. In experiments, the framework achieved strong score correlations and successfully improved over 73% of model responses with a 93.28% non-degradation rate.

    Beyond Right and Wrong: Evaluating Second-order Social Reasoning in Large Language Models

    To evaluate how Large Language Models (LLMs) understand 'metanorms'—the social expectations governing how humans react to rule violations—researchers introduced a new benchmark dataset and evaluation framework called NormReact. The study reveals that current LLMs significantly overpredict harsh punishments and negative sanctions compared to actual human judgment. Consequently, current AI systems risk providing a distorted view of social regulation by over-representing punitive responses and under-representing real-world human tolerance and restraint.

    AutoFyn Technical Report: Non-Parametric Expert Iteration for Long-Horizon Agents

    **AutoFyn** introduces a novel agent framework that enhances frozen AI models over long-horizon tasks by updating persistent state—such as memory files and reports—rather than modifying model weights. The system employs an orchestrator to explore multiple solutions and a verifier to score progress, distilling verified feedback back into the durable state to guide subsequent rounds. Demonstrated across mathematics, data science, and cybersecurity, AutoFyn outperformed default coding agents on IMO problems, topped the Spider 2.0 benchmark, and discovered 16 maintainer-confirmed software vulnerabilities.

    Iris: Climbing to the Search Frontier

    Researchers have introduced Iris-mini and Iris-pro, two search agents trained using a multi-hop web data pipeline and an alternating 'SFT-RL climbing' procedure optimized against live search. Evaluated with inference-time context management, both models achieved the strongest overall results among open-source search agents in their parameter classes across benchmarks such as BrowseComp, DeepSearchQA, and HLE. The authors plan to publicly release the model weights alongside the complete data construction, training, and evaluation recipes.

    Harbor Adapters and Harbor-Index: Infrastructure and a Curated Meta-Dataset for Large-Scale Agentic Evaluation

    To simplify agentic evaluation across complex environments, researchers developed Harbor Adapters, an open-source infrastructure that adapts over 80 benchmarks for testing arbitrary AI agents. Using this platform, the authors conducted a large-scale evaluation of eight models across 54 benchmarks and introduced Harbor-Index, a curated and affordable meta-dataset of 82 challenging tasks from 29 benchmarks. Across all evaluated model-harness configurations on Harbor-Index, no model exceeded a 30% pass rate, demonstrating the suite's high difficulty and effectiveness for testing agent capabilities.

    From Matching Models to Recruiting Agents: A Systematized Narrative Review of AI Recruitment Systems, Evaluation, and Governance

    This systematized narrative review traces the evolution of AI recruitment systems from basic profile-matching models to multi-stage workflows and tool-using recruiting agents. Based on an analysis of 40 representative works, the study highlights critical gaps, such as reliance on private data, hidden pipeline failures, and a complete lack of joint evaluations covering utility, fairness, privacy, and security. To address these limitations, the authors introduce a staged evaluation framework and an agenda for auditable, evidence-grounded recruitment systems governed by explicit cost and risk constraints.

    EXAONE Forecast for Finance

    **EXAONE Forecast for Finance** is a new time series foundation model specifically designed to address the computational and missing-data challenges inherent to financial forecasting. By replacing heavy self-attention mechanisms with efficient linear-time operators and pretraining on a massive multi-asset dataset, the model effectively captures complex market dynamics. Consequently, EXAONE Finance achieved state-of-the-art performance on the FinVerse benchmark, ranking first in point-forecast accuracy, cross-sectional asset ranking, and portfolio profitability.

    Data-Optimized Contingency Screening: A Machine Learning Approach to Power System Security

    Researchers have developed a machine learning framework using Random Forest, SVM, and KNN algorithms to classify power system contingencies into safe, moderate, or severe risk levels to prevent grid failures. By combining these models with pre-processing techniques like PCA and SMOTE, Random Forest achieved the highest performance with F1 scores up to 0.97, with PCA contributing the most to model accuracy. Ultimately, the study highlights machine learning as a scalable and powerful alternative to traditional contingency analysis for real-time power system security assessment.
