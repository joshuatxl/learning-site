# HyperWorld: Hypergraph-Structured State Serialization Improves Learned Textual World Models

A new study introduces HyperWorld, a framework designed to evaluate how different state serialization structures impact the performance of learned textual world models in AI agents. Researchers compared raw text observations against three symbolic state representations: independent sentences, pairwise triples, and entity-centered hyperedges that group related facts. Across various tests, hyperedge serialization consistently demonstrated superior results for small-to-medium-sized models ranging from 0.5B to 1.5B parameters. Furthermore, the hyperedge representation achieved the highest overall success rate during downstream planning tasks compared to the other tested formats. Ultimately, the key takeaways are that higher-order hypergraph state organization serves as a simple yet powerful inductive bias for textual world models, providing the most significant benefits when model capacity is restricted or when agents operate in novel, out-of-distribution environments.
