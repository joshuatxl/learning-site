# Gemini Omni 1.1 Flash lets you build with more control

Google has announced Gemini Omni 1.1 Flash, an upgraded lightweight AI model designed for high-speed performance and minimal latency. This release grants developers significantly more control through expanded parameters for system instructions, precise output formatting, and granular safety controls. Despite its streamlined footprint, the model preserves powerful multimodal capabilities across text, audio, and visual data streams. Improved API infrastructure further simplifies enterprise integration, facilitating seamless deployment into live software environments. **Key Takeaways:** Gemini Omni 1.1 Flash delivers a faster, cheaper, and highly customizable AI model that empowers developers to build precise, real-time multimodal applications at scale.
