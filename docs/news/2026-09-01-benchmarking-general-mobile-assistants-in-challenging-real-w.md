# Benchmarking General Mobile Assistants in Challenging Real-World Scenarios

A new benchmark called GMA (General Mobile Assistants) has been developed to evaluate autonomous AI agents across diverse, complex mobile environments that existing benchmarks fail to capture. Built around seven open-source applications, GMA introduces 300 tasks across four difficulty tiers, ranging from basic atomic actions to intricate multi-step workflows. When researchers evaluated eight leading frontier models, they found that AI performance declined significantly as task difficulty increased, proving that current agents are not yet ready to reliably handle realistic user needs. The study also demonstrated that optimizing an agent's harness design—such as implementing explicit state tracking and context retention—can meaningfully boost performance on complex workflows. Ultimately, the key takeaway is that while current mobile AI agents fall far short of real-world reliability, GMA offers a vital testbed showing that thoughtful harness engineering is essential to closing this capability gap.
