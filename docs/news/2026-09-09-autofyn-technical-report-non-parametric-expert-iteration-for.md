# AutoFyn Technical Report: Non-Parametric Expert Iteration for Long-Horizon Agents

![](/static/browse/0.3.4/images/arxiv-logo-fb.png)

**AutoFyn** introduces a novel agent framework that enhances frozen AI models over long-horizon tasks by updating persistent state—such as memory files and reports—rather than modifying model weights. The system employs an orchestrator to explore multiple solutions and a verifier to score progress, distilling verified feedback back into the durable state to guide subsequent rounds. Demonstrated across mathematics, data science, and cybersecurity, AutoFyn outperformed default coding agents on IMO problems, topped the Spider 2.0 benchmark, and discovered 16 maintainer-confirmed software vulnerabilities.
