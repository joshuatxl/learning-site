# IBM releases SOTA Granite Time Series PatchTST-FM-r2 model with commercial-friendly license

<h2><a href="https://huggingface.co/blog/ibm-research/ibm-releases-sota-granite-time-series#ibm-releases-sota-granite-time-series-patchtst-fm-r2-model-with-commercial-friendly-license"> </a> IBM releases SOTA Granite Time Series PatchTST-FM-r2 model with commercial-friendly license</h2><p><em>High-performance zero-shot forecasting with commercial-friendly open licensing</em></p><p>Time-series foundation models are changing the way forecasting systems are built. Instead of training and maintaining a separate model for every dataset, users can use a pretrained model and generate forecasts zero-shot.</p><p>IBM has released <a href="https://huggingface.co/ibm-granite/granite-timeseries-patchtst-fm-r2"><strong>Granite Time Series PatchTST-FM-r2</strong></a>, the latest model in the Granite TSFM family (<a href="https://github.com/ibm-granite/granite-tsfm">github</a>, <a href="https://research.ibm.com/blog/time-series-ai-enterprise">blog</a>). PatchTST-FM-r2, a new version of its predecessor <a href="https://huggingface.co/ibm-granite/granite-timeseries-patchtst-fm-r1">PatchTST-FM-r1</a>, combines an updated architecture, a larger pretraining corpus, probabilistic forecasting, support for imputation of missing values, and strong zero-shot performance in a ~<strong>385M-parameter</strong> model.</p><p>As of September 8, 2026, the model is the <strong>top performing zero-shot model released under a permissive, commercial-friendly open-source license (Apache 2.0 and OpenMDW 1.0) among replicable, zero-shot models on the GIFT-Eval leaderboard</strong>. GIFT-Eval is a comprehensive time series forecasting benchmark designed to evaluate models across diverse forecasting scenarios; the model ranks #2 overall among replicable, zero-shot models.</p><p><strong>The model weights, architecture, inference pipeline, and code needed to reproduce the benchmark results are all available.</strong></p><p>In this blog we describe the model, dive deeper into the benchmarking results and the model architecture, discuss the training data and licensing, and provide code examples illustrating how to use the model. Finally, we also highlight how the models from the Granite Time Series family can be used in streaming applications in production setting leveraging <a href="https://events.confluent.io/early-access-flink-features">Confluent product</a>.</p><p><strong>Ready to try it?</strong> <a href="https://huggingface.co/ibm-granite/granite-timeseries-patchtst-fm-r2"><strong>Open Granite Time Series PatchTST-FM-r2 on Hugging Face</strong></a></p><h2><a href="https://huggingface.co/blog/ibm-research/ibm-releases-sota-granite-time-series#tldr"> </a> TL;DR</h2><ul><li>General-purpose zero-shot forecasting for demand, prices, energy loads, traffic, telemetry, and other time series.</li><li>Approximately 385M parameters, context length up to 8,192, flexible forecast lengths, and probabilistic forecasts through a 99-quantile prediction head.</li><li>The model backbone is constructed from conformer blocks that combine multi-head self-attention with temporal convolution to capture long- and short-range temporal structure.</li><li>Permissively licensed model with top performance in the replicable zero-shot category of the GIFT-Eval benchmark (dual-licensed under Apache-2.0 and OpenMDW-1.0, users may select either license).</li><li>Available open weights, architecture, inference pipeline, and code to reproduce the benchmark.</li></ul><h2><a href="https://huggingface.co/blog/ibm-research/ibm-releases-sota-granite-time-series#strong-zero-shot-forecasting-on-gift-eval"> </a> Strong zero-shot forecasting on GIFT-Eval</h2><p>A foundation model is most useful when it generalizes to time series it has not been specifically trained on. For that reason, we focus first on zero-shot performance.</p><p>GIFT-Eval provides a broad evaluation of forecasting models across heterogeneous datasets and forecasting scenarios. When restricting the leaderboard to models that are zero-shot, replicable, and evaluated without test leakage, PatchTST-FM-r2 ranks second for both CRPS and MASE as of September 8, 2026, as illustrated in Figures 1 and 2 (lower values are better for both metrics). Importantly, <strong>PatchTST-FM-r2 is the highest-performing model in the same category among models with permissive, commercial-friendly licensing.</strong></p>
