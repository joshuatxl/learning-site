# Hypothesize, Evaluate, Refine: A Scientific Agent for PDE Discovery with Unknown Spatial Coefficient Fields

Researchers have presented HER-PDE, a scientific-agent framework designed to discover governing partial differential equation (PDE) structures alongside unknown spatial coefficient fields. To address the challenge of coupled PDE operators and spatial fields, the agent analyzes noisy trajectories from different excitations to form and refine expression-tree hypotheses. The framework evaluates these structures using bidirectional cross-excitation transfer and subsequently audits the selected governing law on a sealed temporal interval. When tested on five two-dimensional systems with five percent relative Gaussian state noise, the agent successfully recovered the exact generating operator in all five cases. Ultimately, the key takeaways demonstrate that this agent-guided refinement process can successfully recover heterogeneous governing laws without prescribing a parametric form for their spatial coefficients, achieving a median Pearson correlation of approximately 0.85 across nine unknown fields.
