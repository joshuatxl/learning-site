# Introducing @huggingface/kernels: 200+ WebGPU Kernels for Local AI

Hugging Face has officially launched `@huggingface/kernels`, a new open-source library containing over 200 optimized WebGPU kernels for local AI execution. Designed to run directly within web browsers, this tool leverages client-side GPU power to execute complex machine learning operations efficiently. The collection includes essential, highly optimized building blocks for common AI tasks, such as matrix multiplication, attention layers, and quantization techniques. By shifting processing entirely to the user's device, the package eliminates latency issues and removes the need for continuous cloud infrastructure. Ultimately, the key takeaways are that `@huggingface/kernels` significantly boosts browser-based AI performance, drastically lowers developer hosting costs, and provides a privacy-first solution for local model deployment.
